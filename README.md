# 🔎 SearchLab — Search Algorithm Visualizer

SearchLab is an interactive web-based application designed to make searching algorithms easier to understand through step-by-step visualization and interactive execution.

It demonstrates:

- 🔹 **Linear Search** — O(n)
- 🔹 **Binary Search** — O(log n)
- 🔹 **Jump Search** — O(√n)
- 🔹 **Interpolation Search** — Average O(log log n)

The application provides visual feedback for each comparison, shows whether the target is found, tracks search steps, and helps users understand algorithm complexity and performance.

## 🎯 Purpose

SearchLab was developed as a **learning project** to understand and visualize searching algorithms in an interactive way, making concepts easier to explore than through theoretical explanations alone.

## 📖 Algorithms Covered

| Algorithm | Best Case | Average Case | Worst Case |
|---|---:|---:|---:|
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Jump Search | O(1) | O(√n) | O(√n) |
| Interpolation Search | O(1) | O(log log n)* | O(n) |

> \*Interpolation Search achieves O(log log n) average performance under suitable data distribution assumptions.
